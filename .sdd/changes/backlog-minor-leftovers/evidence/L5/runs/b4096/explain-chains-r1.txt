Este módulo gestiona cadenas de respaldo para roles de modelos de IA. Cuando el modelo principal falla, el sistema salta a alternativas definidas en estas cadenas, las cuales se declaran por rol y se resuelven dinámicamente con la configuración vigente, garantizando resiliencia ante cambios en los modelos por defecto. La función resolve(role) analiza la configuración, valida cada paso contra roles válidos, modelos permitidos o el marcador loaded (modelos ya cargados en memoria), descarta entradas inválidas, elimina duplicados y omite el modelo principal. El marcador loaded se resuelve en tiempo real mediante loaded_members(), que consulta un proveedor registrado y filtra el modelo fallido. El código también acepta sinónimos obsoletos con advertencias. Si no hay proveedor registrado, loaded retorna vacío, reduciendo las cadenas a saltos directos entre roles. Finalmente, funciones auxiliares formatean las cadenas y el estado de residentes para informes de estado, priorizando flexibilidad, validación estricta y resolución dinámica sin acoplarse a nombres fijos.
