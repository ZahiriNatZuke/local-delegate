Este módulo gestiona cadenas de respaldo para roles de modelos (`code`, `long`, `mechanical`). Cuando falla el modelo principal, el sistema recorre una lista ordenada de alternativas definida por rol. La función `resolve()` lee la configuración vigente, valida cada paso contra roles válidos, modelos permitidos o el marcador especial `LOADED` (modelos ya cargados), elimina duplicados y el modelo principal, y registra sinónimos obsoletos o valores inválidos. `LOADED` no se expande al definir la cadena, sino que se resuelve dinámicamente en `loaded_members()`, que consulta un proveedor registrado para obtener los modelos activos en ese instante; si no hay proveedor, devuelve vacío y la cadena se acorta. Las funciones `describe()` y `residents_text()` generan reportes de estado para monitoreo. En esencia, el código centraliza la lógica de degradación elegante, asegurando que los saltos entre modelos sean seguros, configurables y dependientes del estado actual del sistema.
