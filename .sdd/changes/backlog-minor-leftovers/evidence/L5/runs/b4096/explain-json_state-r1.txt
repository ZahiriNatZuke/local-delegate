Este código proporciona funciones seguras para leer y escribir archivos JSON compartidos entre múltiples procesos, evitando condiciones de carrera y corrupción de datos. La función `read_json` abre el archivo, analiza su contenido y verifica que sea un diccionario; si falta, falla la lectura o el formato es inválido, devuelve un diccionario vacío. La función `write_json_atomic` garantiza escrituras atómicas: crea un archivo temporal cuyo nombre incluye el PID del proceso actual para evitar colisiones cuando varios procesos escriben simultáneamente. Escribe los datos en este temporal y luego lo reemplaza atómicamente sobre el archivo original, asegurando que los lectores nunca accedan a contenido parcial o mezclado. Finalmente, intenta eliminar el temporal; si falla (común en Windows por bloqueos de antivirus), ignora el error silenciosamente para no enmascarar excepciones reales y mantener la estabilidad. El diseño prioriza la integridad de los datos y la robustez frente a restricciones del sistema operativo.
