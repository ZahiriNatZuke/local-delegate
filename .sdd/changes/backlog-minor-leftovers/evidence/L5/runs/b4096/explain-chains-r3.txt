Este módulo gestiona cadenas de respaldo para roles de modelos (`code`, `long`, `mechanical`). Cuando el modelo principal falla, el sistema intenta saltar a alternativas definidas en estas cadenas. La función `resolve(role)` parsea la configuración del rol, valida cada paso contra roles o modelos permitidos, elimina duplicados y el modelo principal, e ignora entradas inválidas. El paso especial `LOADED` representa modelos ya cargados en memoria; se resuelve dinámicamente en tiempo de ejecución mediante `loaded_members()`, que consulta un proveedor registrado. Si no hay proveedor activo, la cadena se vacía. El código también normaliza sinónimos obsoletos (`residente`, `resident`) y consulta modelos residentes con TTL cero. Finalmente, `describe()` genera líneas de estado para monitoreo. En esencia, traduce configuraciones estáticas en listas de candidatos válidas y actualizadas, garantizando que los saltos de modelo sean seguros, eficientes y adaptados al estado actual del sistema.
