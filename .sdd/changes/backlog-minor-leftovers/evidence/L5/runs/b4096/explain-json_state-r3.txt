Este código gestiona archivos JSON compartidos entre múltiples procesos de forma segura, evitando lecturas corruptas y escrituras que se solapen. La función `read_json` intenta abrir y analizar el archivo; si falla por inexistencia, permisos o formato inválido, devuelve un diccionario vacío como valor seguro. Para escribir, `write_json_atomic` implementa una estrategia atómica: genera un archivo temporal único por proceso añadiendo su PID al nombre (`{nombre}.{pid}.tmp`), lo que impide que varios procesos sobrescriban el mismo temporal y mezclen datos. Luego, serializa los datos a JSON y los escribe en ese temporal. Finalmente, usa `replace()` para moverlo al archivo original de forma atómica. En el bloque `finally`, intenta eliminar el temporal, pero ignora silenciosamente los errores de sistema (típicos en Windows por bloqueos de antivirus), evitando así enmascarar fallos reales y priorizando la estabilidad sobre la limpieza perfecta. Este enfoque garantiza integridad de datos en entornos concurrentes con restricciones de sistema operativo.
