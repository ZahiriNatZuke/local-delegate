Este módulo gestiona cadenas de respaldo para roles de modelos (`code`, `long`, `mechanical`). Cuando el modelo principal falla, el sistema salta secuencialmente a los pasos definidos en la cadena. La configuración se lee dinámicamente; si no existe, usa cadenas por defecto. La función `resolve()` procesa los pasos crudos: valida que sean roles conocidos, modelos permitidos o el marcador `loaded`, ignora valores inválidos, elimina duplicados y excluye el modelo principal. Los sinónimos obsoletos (`residente`, `resident`) se mapean a `loaded` y se registran para avisos. El paso `loaded` no se resuelve al inicio, sino en tiempo de ejecución mediante `loaded_members()`, que consulta un proveedor registrado para obtener los modelos ya cargados en ese momento. Las funciones `describe()` y `residents_text()` generan reportes de estado, consultando la topología y configuraciones activas. En resumen, el código centraliza la lógica de fallback, asegurando que las cadenas se adapten a la configuración vigente y a los modelos disponibles sin recargar el sistema.
