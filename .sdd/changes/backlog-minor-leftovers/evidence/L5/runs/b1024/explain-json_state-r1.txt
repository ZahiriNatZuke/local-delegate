Este módulo gestiona archivos JSON compartidos entre múltiples procesos de forma segura. La función `read_json` lee un archivo y devuelve su contenido como diccionario; si el archivo no existe, es ilegible o no es un objeto JSON válido, retorna `{}` silenciosamente para evitar interrupciones. La función `write_json_atomic` garantiza escrituras atómicas que previenen colisiones o datos mezclados cuando varios procesos escriben simultáneamente. Para lograrlo, genera un archivo temporal cuyo nombre incluye el identificador del proceso (`pid`), asegurando unicidad durante la escritura. Tras guardar los datos, utiliza `replace()` para reemplazar el archivo original de forma atómica. En el bloque `finally`, intenta eliminar el temporal; si falla (frecuente en Windows por bloqueos de antivirus), ignora el error para no enmascarar excepciones reales, priorizando la estabilidad del flujo principal. El diseño responde a lecciones prácticas: mantener un único archivo compartido en lugar de copiarlo por proceso evita inconsistencias, y el manejo tolerante a fallos del sistema operativo asegura que la aplicación continúe operando incluso bajo restricciones de permisos o bloqueos externos.
