Este módulo gestiona cadenas de respaldo para roles de generación de texto (`code`, `long`, `mechanical`). Cuando falla el modelo principal, el sistema salta secuencialmente a los pasos definidos en la cadena correspondiente. Las cadenas se configuran por rol y se resuelven en tiempo de ejecución, filtrando duplicados, el modelo principal y valores inválidos. El paso especial `loaded` no se resuelve al definir la cadena, sino dinámicamente al saltar, consultando un proveedor registrado que devuelve los modelos ya cargados en memoria, excluyendo el fallido. Si no hay proveedor, `loaded` queda vacío y la cadena efectiva solo incluye modelos estáticos. El código también maneja sinónimos obsoletos (`residente`, `resident`) mapeándolos a `loaded` con una advertencia, y proporciona funciones para generar estados descriptivos (`describe`) y consultar modelos residentes. Todo el enrutamiento y la ejecución de saltos se delegan a `server._next_hop`, manteniendo este módulo enfocado únicamente en la validación y construcción de las cadenas válidas según la configuración vigente.
