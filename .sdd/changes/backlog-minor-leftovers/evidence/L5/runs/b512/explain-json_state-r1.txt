Este código implementa dos funciones para gestionar archivos JSON compartidos entre múltiples procesos de forma segura. `read_json` lee un archivo JSON y devuelve su contenido como diccionario. Si el archivo no existe, no se puede leer o su contenido no es un diccionario válido, retorna un diccionario vacío, evitando así excepciones que interrumpan la ejecución.

`write_json_atomic` escribe datos en el archivo JSON de manera atómica para evitar condiciones de carrera y corrupción de datos cuando varios procesos escriben simultáneamente. En lugar de modificar el archivo original directamente, crea un archivo temporal cuyo nombre incluye el PID del proceso actual. Tras escribir los datos en JSON, utiliza `replace()` para renombrar el temporal sobre el archivo original, operación atómica que garantiza que los lectores siempre vean un archivo completo o inexistente. Finalmente, intenta eliminar el temporal. Si falla (común en Windows por bloqueos de antivirus), ignora el error silenciosamente para no enmascarar fallos reales y permitir que el archivo temporal huérfano sea limpiado posteriormente, priorizando la estabilidad sobre la limpieza estricta.
