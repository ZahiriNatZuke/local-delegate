Este código implementa funciones seguras para leer y escribir archivos JSON compartidos entre múltiples procesos, evitando corrupción y conflictos de concurrencia. La función `read_json` abre el archivo especificado, carga su contenido JSON y devuelve el diccionario resultante. Si el archivo no existe, no se puede leer o su contenido no es un objeto JSON válido, retorna un diccionario vacío `{}` sin interrumpir la ejecución.

La función `write_json_atomic` garantiza escrituras atómicas y sin mezclas. Para ello, escribe los datos en un archivo temporal cuyo nombre incluye el identificador del proceso (`pid`), evitando que varios procesos sobrescriban el mismo temporal simultáneamente. Una vez escrito, reemplaza el archivo original de forma atómica. En la fase de limpieza, ignora silenciosamente los errores de eliminación del temporal, un manejo necesario en Windows donde el antivirus suele bloquear archivos abiertos. Si se lanzara la excepción, enmascararía fallos reales y complicaría la depuración, prefiriéndose un archivo temporal huérfano antes que una ejecución fallida. En conjunto, el código prioriza la robustez y la compatibilidad multiplataforma en entornos con escritura concurrente.
