Este módulo gestiona cadenas de respaldo para roles de modelos de IA (code, long, mechanical). Cuando falla el modelo principal, el sistema salta al siguiente paso válido de la cadena correspondiente. Las cadenas se definen por rol y se resuelven dinámicamente con la configuración actual, lo que permite sobrevivir a cambios en los modelos por defecto. La función resolve(role) parsea la configuración, elimina duplicados, excluye el modelo principal y filtra entradas inválidas, las cuales se registran como ignoradas. Mapea sinónimos obsoletos (residente, resident) al paso especial loaded, el cual se resuelve en tiempo de ejecución mediante un proveedor registrado. Si no hay proveedor, loaded devuelve vacío y la cadena efectiva se reduce a los modelos estáticos. El módulo también expone funciones para generar descripciones de estado y manejar modelos residentes con tiempo de vida cero, asegurando un comportamiento robusto y monitoreable.
