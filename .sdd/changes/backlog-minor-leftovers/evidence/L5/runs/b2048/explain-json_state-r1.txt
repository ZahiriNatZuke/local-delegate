Este código implementa dos funciones para gestionar archivos JSON compartidos entre procesos de forma segura. `read_json` lee un archivo y devuelve su contenido como diccionario. Si el archivo no existe, es ilegible o no contiene un objeto JSON válido, retorna un diccionario vacío para evitar excepciones. `write_json_atomic` garantiza escrituras atómicas y evita corrupción por accesos simultáneos. Crea un archivo temporal cuyo nombre incluye el PID del proceso, impidiendo que múltiples procesos sobrescriban el mismo temporal y mezclen datos. Escribe el JSON en ese temporal y utiliza `replace()` para reemplazar el archivo original de forma atómica. En la fase de limpieza, intenta borrar el temporal. Si falla (frecuente en Windows por bloqueos de antivirus), ignora silenciosamente el error para no enmascarar fallos reales, priorizando la estabilidad del programa sobre la eliminación inmediata del archivo temporal huérfano.
