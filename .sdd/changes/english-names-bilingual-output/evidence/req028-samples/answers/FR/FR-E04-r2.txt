Ce code définit le point d'entrée principal (`main`) d'une application Python, servant de façade unique pour gérer deux modes d'exécution distincts : une interface en ligne de commande (CLI) et un serveur MCP (Model Context Protocol). La fonction examine les arguments de la ligne de commande (`sys.argv`). Si des arguments sont présents, elle importe dynamiquement le module `cli` et délègue l'exécution à celui-ci, permettant ainsi de traiter les sous-commandes ou l'aide. Cette approche évite les cycles d'importation et réduit la charge au démarrage, car le parser CLI n'est chargé que si nécessaire.

En l'absence d'arguments, l'application se comporte comme un serveur MCP standard en mode stdio. Elle émet d'abord un avertissement sur la sortie d'erreur si l'entrée standard est interactive (terminal), pour prévenir l'utilisateur qu'il doit fournir des données JSON-RPC. Selon la configuration, elle peut également lancer automatiquement un backend ou démarrer un serveur de métriques web en arrière-plan. Enfin, elle gère proprement l'interruption du processus (Ctrl+C) en capturant l'exception `KeyboardInterrupt` pour fermer le serveur silencieusement sans générer de traces d'erreur inutiles, assurant ainsi une sortie propre et un code de retour indiquant une fin normale.
