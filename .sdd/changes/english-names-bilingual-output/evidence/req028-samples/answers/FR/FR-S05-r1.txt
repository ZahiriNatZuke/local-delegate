## pycparser v3.00
C'est un analyseur syntaxique écrit uniquement en Python.

## Introduction
**Qu'est-ce que pycparser ?** C'est un module Python pour analyser le code C. **À quoi sert-il ?** Il permet l'obfuscation, l'analyse statique ou la création de compilateurs. **Quelle version de C est supportée ?** Il cible le standard C99 et partiellement C11. **Quelle grammaire suit-il ?** Il respecte l'annexe A du standard C99. **Quelle est sa licence ?** Il utilise la licence BSD. **Détails de contact** : Les utilisateurs peuvent soumettre des problèmes ou des fonctionnalités via GitHub.

## Installing
**Prérequis** : Il nécessite des versions modernes de Python sur divers systèmes. **Processus d'installation** : L'outil s'installe via la commande `pip install pycparser`.

## Using
**Interaction avec le préprocesseur C** : Le module nécessite un code préprocesse pour fonctionner correctement. **Qu'en est-il des en-têtes de la bibliothèque standard C ?** Il est recommandé d'utiliser des en-têtes factices fournis dans `utils/fake_libc_include`. **Utilisation de base** : Des exemples sont disponibles dans le répertoire `examples/`. **Utilisation avancée** : La documentation se trouve dans `pycparser/c_parser.py` et `pycparser/_c_ast.cfg`.

## Modifying
Les nœuds AST sont générés par `_ast_gen.py` à partir de `_c_ast.cfg`.

Le paquet contient le code source, des exemples, des tests et des fichiers de configuration.
