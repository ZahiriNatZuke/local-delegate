## Introducción
Ce document présente les recommandations pour utiliser les hooks de Claude Code afin de suggérer la délégation de tâches.

## Hooks
**`suggest_delegate_prompt.py` — `UserPromptSubmit`** Détecte les intentions de résumé ou de traduction pour proposer une délégation sans influencer la décision finale.
**`suggest_delegate_read.py` — `PreToolUse`, matcher `Read`** Propose de déléguer la lecture de fichiers volumineux, mais reste désactivé par défaut pour éviter le bruit.
**`suggest_delegate_shell.py` — `PreToolUse`, matcher `Bash|PowerShell`** Identifie les commandes de lecture de fichiers simples pour suggérer une délégation de contenu.
**`record_call.py` — `PreToolUse`, matcher `mcp__local-delegate__.*`** Enregistre systématiquement les appels aux outils de délégation pour le suivi des coûts et des métriques.
**`suggest_lint_summary.py`** Ce script a été retiré le 2026-09-08 en raison d'un taux de réussite trop faible.

## Instalación
L'installation s'effectue via `local-delegate install`, copiant les scripts dans le répertoire des hooks de l'utilisateur.

## Configuración
Les variables d'environnement permettent de gérer l'activation des hooks, les seuils de taille en KB et la télémétrie.

## Verificación manual
L'utilisateur peut tester les suggestions avec des prompts de résumé ou vérifier l'absence de suggestions pour les tests.

## Piloto A/B
Le test compare des sessions avec et sans hooks en utilisant une suite de prompts spécifique.
**Resultado del piloto de 2026-07-23** Les hooks actifs ont amélioré l'adoption, bien que le hook de lecture nécessite encore des ajustements.
