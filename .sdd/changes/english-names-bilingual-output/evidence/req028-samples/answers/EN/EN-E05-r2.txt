This Python script prepares Markdown files from a `docs/wiki/` directory for publication as a GitHub Wiki. GitHub Wikis operate in a separate repository and serve flat files, meaning relative links like `../recipes/ollama.md` break because the directory structure does not exist in the wiki context. The script solves this by converting internal relative links into absolute URLs pointing to the main source repository.

The core logic resides in the `convert` function, which uses a regular expression to find Markdown links. For each link, the `convert_destination` function checks if it is external, an anchor, or a relative path. If it is a relative path starting with `..`, the script resolves the target file’s absolute path relative to the project root. It then constructs a GitHub blob URL (e.g., `https://github.com/.../blob/main/path/to/file.md`). External links, anchors, and internal wiki links (those not starting with `..`) remain unchanged to preserve navigation within the wiki.

The `main` function handles command-line arguments. It can run in two modes: `--check` mode, which only reports which links would be converted without writing files, or write mode, which outputs the converted Markdown files to a specified destination directory. The script processes all `.md` files in the source directory, applies the conversion, prints a summary of changes, and saves the updated content. This ensures that the source documentation remains navigable with relative links locally, while the published wiki maintains functional hyperlinks via absolute URLs. The script uses only Python standard libraries, ensuring it runs without external dependencies in CI/CD workflows.
