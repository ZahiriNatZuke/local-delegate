This Python script automates the preparation of a static website for GitHub Pages by injecting the current project version into the generated files. It reads the version string directly from `pyproject.toml` using the standard library's `tomllib`, ensuring a single source of truth and avoiding manual updates across multiple configuration files.

The core logic involves copying the `site/` directory to a `_site/` destination, excluding specific source files (those ending in `.src.html`) that are not part of the public site. During this process, the script scans all HTML, CSS, JavaScript, JSON, and Web Manifest files for a specific placeholder marker, `__LD_VERSION__`. If found, it replaces this marker with the actual version number retrieved from the project configuration. The script ensures cross-platform compatibility by explicitly setting the newline character to `\n` when writing files, preventing Windows-style CRLF line endings in web assets.

The tool supports two modes of operation. In the default mode, it performs the build, replacing markers and printing a summary of modified files. Alternatively, using the `--check` flag, it runs a validation pass to ensure no files in the destination directory still contain the unresolved marker. This check is crucial for CI/CD pipelines to catch deployment errors where the version injection might have failed. By relying solely on the Python standard library, the script remains lightweight and dependency-free, making it ideal for execution in automated workflows without requiring external package installations.
