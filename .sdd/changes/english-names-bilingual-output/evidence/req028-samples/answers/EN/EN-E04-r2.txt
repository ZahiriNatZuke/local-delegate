This Python script sanitizes HTML fixture files by removing visitor-specific tracking data while preserving public site configuration. It targets anonymous analytics IDs, session identifiers, IP-derived country codes, and Content Security Policy nonces, replacing them with neutral placeholders like "00000000-0000-0000-0000-000000000000" or "ZZ". The script uses regex patterns to identify these keys in various formats (HTML attributes, JSON, escaped strings) regardless of surrounding whitespace or quote styles.

The core logic distinguishes between long and short values. Long identifiers (16+ characters) are assumed to be unique per visit and are globally replaced throughout the file. Short values (like country codes) are replaced only where matched by the pattern to avoid altering legitimate public text. The process is idempotent; running it on already-cleaned files produces no changes. The script reads HTML files from a specified fixtures directory or command-line arguments, processes them in UTF-8, and writes back only if modifications occur. It also provides a `leftovers()` function to verify cleanliness by checking for any remaining non-neutral values. This ensures test fixtures remain reproducible and free from sensitive, per-user data while maintaining the structural integrity of the original pages for price and limit extraction tests.
