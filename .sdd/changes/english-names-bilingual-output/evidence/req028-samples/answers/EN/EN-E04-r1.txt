This Python script sanitizes HTML fixture files by removing visitor-specific tracking data while preserving public site configuration. It targets anonymous analytics IDs, session IDs, IP-derived country codes, and Content Security Policy nonces, replacing them with neutral placeholders like "00000000-0000-0000-0000-000000000000" or "ZZ". The script uses regular expressions to identify these keys in various formats (HTML attributes, JSON, escaped strings) regardless of surrounding whitespace or quote styles.

The core logic distinguishes between long identifiers (length ≥ 16) and short ones. Long values, assumed to be unique per visit, are globally replaced throughout the file. Short values, which might be generic codes (e.g., country codes) appearing elsewhere in the page, are replaced only within the specific matched context to avoid altering public content. This ensures idempotency: running the script on already-cleaned files produces no changes.

The script processes files from a specified directory or command-line arguments. It reads each file as bytes, decodes to UTF-8, applies cleaning, and writes back only if modifications occurred, preserving original line endings. A helper function `leftovers` verifies cleanliness by checking for any remaining non-neutral tracked values. This approach maintains the integrity of test fixtures by stripping sensitive, per-user data while keeping the structural and public content of the pages intact for reliable automated testing.
