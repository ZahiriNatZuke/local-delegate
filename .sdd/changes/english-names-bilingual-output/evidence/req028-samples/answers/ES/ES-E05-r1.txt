El script `validate_counter.py` genera un informe JSON para la revisión manual de la validez de contadores en respuestas de lenguaje natural. Su objetivo es comparar dos implementaciones de lógica de detección de "invenciones" (datos falsos o no verificados): una versión principal (`score_lint_fidelity_main.py`) y una corregida (`score_lint_fidelity.py`).

El programa recibe pares de argumentos `ANSWER=LOG`, donde `ANSWER` es el texto de la respuesta y `LOG` es el registro de referencia. Para cada par, extrae números (dígitos o palabras) y nombres de archivos del texto utilizando expresiones regulares definidas en el módulo nuevo. Luego, itera sobre estos elementos únicos, obteniendo un contexto textual alrededor de cada coincidencia.

Para cada elemento, el script determina si fue clasificado como "inventado" por ambos contadores. Compara los resultados de las funciones `count_inventions` de ambos módulos. El JSON de salida contiene, por cada respuesta, una lista de objetos que detallan el tipo de dato (número o archivo), el token específico, su contexto y dos booleanos (`old_invented` y `new_invented`) que indican si cada contador lo marcó como invención. Esto permite a un revisor humano identificar discrepancias entre la versión antigua y la corregida, facilitando la validación de reglas específicas (como B2d-4) antes de adoptar el nuevo contador. El script maneja la carga dinámica de módulos y asegura que la salida sea legible y estructurada para su análisis posterior.
