## Installing via PIP
Se recomienda usar pip para la instalación. **Instalando globalmente** se pueden instalar objetos COM o servicios mediante un script de post-instalación. **Instalando para MingGW/msys2** se sugiere usar los parches de la comunidad mediante `pacman`. **Corriendo como un Windows Service** requiere una instalación global con privilegios elevados y acceso adecuado a Python.

## Troubleshooting
Ante errores de punto de entrada, se debe ejecutar el script de post-instalación o eliminar copias conflictivas de DLLs en el sistema.

## Building from source
Requiere instalar Visual Studio 2019 y seguir las instrucciones de entorno y construcción.

## Release process
