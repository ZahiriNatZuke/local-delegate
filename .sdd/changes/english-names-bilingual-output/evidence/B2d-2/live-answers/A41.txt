## Introduction
This package provides a minimal, low-level HTTP client designed to perform a single task: sending HTTP requests.

## HTTPCore 2
**Installation** Users can install the basic version or include optional extras for specific protocols and backends.
**Sending requests** The library offers a top-level function for convenience and a connection pool for practical use.
**Motivation** It aims to provide a reusable low-level library with a clear split between networking and logic.
**Dependencies** The package requires `h11` and `truststore`, with optional extras like `anyio`, `trio`, `h2`, and `socksio`.
**Versioning** The project follows the SEMVER policy for all versioning decisions.
