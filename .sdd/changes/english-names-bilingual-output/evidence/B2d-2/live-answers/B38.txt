Este documento describe el paquete `python-discovery`, una biblioteca de Python diseñada para identificar intérpretes de Python instalados en un sistema.  El paquete permite encontrar la versión de Python correcta que coincida con una especificación dada, como `python3.12` o un rango de versiones.  `python-discovery` soporta múltiples métodos de instalación de Python, incluyendo `pyenv`, `mise`, `asdf`, `uv` y el registro de Windows.  La biblioteca funciona con Python 3.8 o superior y puede detectar versiones desde Python 3.6 hasta las más recientes.  El paquete utiliza un caché en disco para acelerar las búsquedas repetidas.  La función principal, `get_interpreter`, acepta diversas especificaciones de versión y devuelve información detallada sobre el intérprete encontrado, como la ruta ejecutable, la implementación y la versión.  La documentación completa se encuentra disponible en `python-discovery.readthedocs.io`.
