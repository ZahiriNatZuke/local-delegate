Este documento describe la biblioteca `identify` para Python, una herramienta para la identificación de archivos.  La biblioteca, versión 2.6.19, proporciona una forma de determinar las características de un archivo, como su tipo (archivo, enlace simbólico, directorio), si es ejecutable y su lenguaje de programación.

La instalación se realiza con `pip install identify`.  La biblioteca ofrece funciones para obtener etiquetas de archivos a partir de la ruta del archivo, el nombre del archivo o el intérprete utilizado.  También incluye una interfaz de línea de comandos (`identify-cli`) para su uso.  Además, proporciona una funcionalidad para identificar el tipo de licencia contenida en un archivo, utilizando un enfoque similar al gem `licensee`.  Este proceso implica la eliminación de líneas de copyright, la normalización del espacio en blanco y la comparación de la distancia de edición.  La biblioteca utiliza una serie de pasos para determinar el tipo de archivo, incluyendo la verificación del tipo, la comprobación de la ejecutable, el reconocimiento de extensiones y la inspección de los primeros bytes del archivo.  Se basa en fuentes externas como `choosealicense.com` para la información de licencias.
