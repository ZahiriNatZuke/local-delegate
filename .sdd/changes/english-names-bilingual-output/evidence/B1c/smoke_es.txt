### --help (root)
uso: local-delegate [-h] [--version]
                    {benchmark,check-llamaswap,init-llamaswap,llamaswap,doctor,serve,recompute-cost,test-window,install,update,uninstall}
                    ...

Instala, diagnostica y sirve local-delegate. Sin subcomando, este binario
arranca el servidor MCP stdio, que es como lo lanzan Claude Code, Codex y
opencode. `check-llamaswap` e `init-llamaswap` piden el extra [llamaswap].

argumentos posicionales:
  {benchmark,check-llamaswap,init-llamaswap,llamaswap,doctor,serve,recompute-cost,test-window,install,update,uninstall}
    benchmark           Ejecuta el corpus v2 de tareas reales contra un
                        backend canary y escribe JSONL.
    check-llamaswap     Valida el presupuesto de VRAM (y opcionalmente RAM) de
                        los groups de un config.yaml.
    init-llamaswap      Genera/actualiza groups en un config.yaml de llama-
                        swap con guardrail de VRAM/RAM.
    llamaswap           Residencia y TTL de los modelos de llama-swap (pide el
                        extra [llamaswap]).
    doctor              Diagnostica el andamiaje (hooks, skill, memoria, MCP),
                        el daemon y el backend.
    serve               Sirve MCP Streamable HTTP (/mcp) y dashboard (/) como
                        daemon singleton.
    recompute-cost      Lee los transcripts de Claude Code y deja en el
                        directorio de logs el relleno de atribución, los
                        agregados de N, el cotejo de precios y los puntos de
                        cuota.
    test-window         Marca ventanas de prueba: las filas del log de uso que
                        caen dentro no cuentan en el panel, en local_status ni
                        en el coste.
    install             Instala hooks, skill, memoria y la entrada MCP en
                        Claude Code / Codex / opencode.
    update              Actualiza el pin, completa lo que falte del andamiaje
                        y deja el daemon arriba.
    uninstall           Revierte lo que instaló `local-delegate install` (solo
                        lo suyo).

opciones:
  -h, --help            muestra esta ayuda y sale
  --version             imprime la versión instalada y termina
