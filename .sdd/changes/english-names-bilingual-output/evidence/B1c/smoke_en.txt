### --help (root)
usage: local-delegate [-h] [--version]
                      {benchmark,check-llamaswap,init-llamaswap,llamaswap,doctor,serve,recompute-cost,test-window,install,update,uninstall}
                      ...

Installs, diagnoses and serves local-delegate. With no subcommand, this binary
starts the stdio MCP server, which is how Claude Code, Codex and opencode
launch it. `check-llamaswap` and `init-llamaswap` need the [llamaswap] extra.

positional arguments:
  {benchmark,check-llamaswap,init-llamaswap,llamaswap,doctor,serve,recompute-cost,test-window,install,update,uninstall}
    benchmark           Runs the v2 corpus of real tasks against a canary
                        backend and writes JSONL.
    check-llamaswap     Checks the VRAM (and optionally RAM) budget of the
                        groups in a config.yaml.
    init-llamaswap      Generates/updates the groups of a llama-swap
                        config.yaml with a VRAM/RAM guardrail.
    llamaswap           Residency and TTL of the llama-swap models (needs the
                        [llamaswap] extra).
    doctor              Diagnoses the scaffolding (hooks, skill, memory, MCP),
                        the daemon and the backend.
    serve               Serves Streamable HTTP MCP (/mcp) and the dashboard
                        (/) as a singleton daemon.
    recompute-cost      Reads the Claude Code transcripts and leaves in the
                        log directory the attribution backfill, the N
                        aggregates, the price check and the quota points.
    test-window         Marks test windows: the usage log rows that fall
                        inside do not count in the panel, in local_status or
                        in the cost.
    install             Installs hooks, skill, memory and the MCP entry in
                        Claude Code / Codex / opencode.
    update              Updates the pin, completes whatever the scaffolding is
                        missing and leaves the daemon up.
    uninstall           Undoes what `local-delegate install` installed (only
                        its own).

options:
  -h, --help            show this help message and exit
  --version             prints the installed version and exits
