Este código implementa un sistema integral de benchmarking para evaluar modelos de lenguaje, centrado en la precisión de la salida y el monitoreo de recursos del sistema. Comienza definiendo estructuras de datos inmutables como `CorpusCase` y `Corpus` para gestionar casos de prueba, junto con funciones de carga y validación como `load_corpus` y `_frozen_source`, que aseguran la integridad de los datos mediante hashes SHA-256. El núcleo de la evaluación incluye `run_execution_checks` para ejecutar código generado de forma segura, `check_counts` para validar reglas específicas y `score_output` para calcular la calidad de las respuestas.

Paralelamente, el script integra un sofisticado monitoreo de hardware, especialmente en Windows. Utiliza `ProcessProbe` y `TypeperfStream` para rastrear el uso de VRAM y memoria privada mediante comandos del sistema y APIs de Windows (`_win32_api`, `read_process_memory`). Clases como `ResourceSampler` y `ThermalTracker` coordinan estas mediciones en segundo plano, gestionando hilos y estados térmicos para evitar sesgos. También incluye utilidades para analizar métricas Prometheus (`parse_prometheus_metrics`) y manejar interacciones con APIs externas mediante `post_attempt` y la clase `Attempt`. Finalmente, `run_benchmark` orquesta todo el proceso, seleccionando casos con `_select_cases` y registrando resultados, mientras `add_parser` configura la interfaz de línea de comandos para el subcomando "benchmark".
